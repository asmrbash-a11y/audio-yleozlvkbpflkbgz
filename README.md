# الوثائقي: «الفتاة التي سقطت من السماء ونجت!»

فيديو موشن جرافيك عمودي (9:16) بأسلوب **Vox documentary** من قصاصات ورقية ورسومات كولاج،
بكابشن عربي متزامن مع الصوت **كلمة بكلمة**، وإعداد وإخراج: **Shaaib Beshr**.

## المهارة المُثبّتة

`https://github.com/mohamedabdou-ai/reel-studio` — قُرئت سكل **reel-studio**
(`.agents/skills/reel-studio/SKILL.md`) وتعليماتها: `instructions/RULES.md`،
`PRODUCTION-MANAGER.md`، `EDITORIAL.md`، `STYLES.md`، `instructions/styles/paper-collage.md`،
`MOTION-CHOICES.md`، `SOUND.md`.

**الستايل المختار:** `paper-collage` (كولاج · ورق متحرك) — لأن القصة تُروى كقطع تُجمَّع:
طائرة، برق، سقوط، غابة، كوخ، إنقاذ. واللوك `film` (حبيبات خفيفة + زوايا أغمق) فوق الرسوم.

بيئة الساندبوكس هنا بلا Chrome/Remotion (والـ setup الرسمي في الستوديو مُثبَّت على ويندوز)،
فطُبِّق محرّك الرسم الذي يفرضه دليل الستايل نفسه — قصاصات ورق، هافتون، شريط لاصق، وتايبوغرافيا عربية —
بـ **Python/PIL + ffmpeg** بنفس القواعد: لا قوالب جاهزة، كل مشهد يُرسم من كلامه.

## خط الإنتاج

1. **الصوت** → تفريغ بـ Whisper ثم تصحيح الكلام يدوياً على النص المطلوب.
2. **المزامنة** → `align.py` يربط كل كلمة مصححة بتوقيتها الحقيقي، ثم يبني 42 سطر كابشن
   و`subtitles.srt` و`data/timeline.json`.
3. **الرسوم** → 10 لوحات كولاج ورقية مولّدة خصيصاً للمشروع (بلا نصوص أو شعارات جاهزة).
4. **المشاهد** → `scenes.py` (وصفات المشاهد) + `engine.py` (كاميرا، انتقالات، كابشن، لوك).
5. **الصوت النهائي** → `audio.py`: التعليق + 65 مؤثراً (ورق، هبوط ناعم، بوب، تكّات، رعد مُصنّع)
   بميزانية −15 LUFS وذروة −1.2 dBFS، والمؤثرات **18.6 dB تحت التعليق** (خافتة في الخلفية).
6. **التصدير** → `render.py full` ثم ترميز two-pass لملف نهائي ≤ 20 ميجابايت.

## الملفات

- `final.mp4` — الفيديو النهائي (≤ 20 ميجابايت).
- `cover.jpg` — غلاف من الفيديو.
- `script.txt` — النص كما ورد في الطلب.
